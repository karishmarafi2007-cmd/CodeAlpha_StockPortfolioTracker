# <h1 align="center">StockPortfolioTracker</h1>

***********ABSTRACT:***********

The Stock Portfolio Tracker is a simple Python application that calculates the value of a stock investment using predefined stock prices. The user enters a stock symbol and quantity, and the program computes the total investment value based on a dictionary of stock prices. This project demonstrates fundamental Python concepts such as dictionaries, user input, conditional statements, arithmetic operations, and optional file handling. It is designed as a beginner-friendly finance-related programming exercise.

***********FEATURES:**********

1)Enter a stock name and quantity 

2)Predefined stock price dictionary 

3)Calculates investment value 

4)Displays the result in the console 

5)Optional saving of results to a text file 

**********TECHNOLOGIES USED:**********

Python 3 

**********HOW TO RUN:********** 

 1. Install Python 3.

2. Save the program as `stock.py`.

3. Open a terminal or command prompt in the project folder.

4.  Run: ```bash python stock_tracker.py ```
